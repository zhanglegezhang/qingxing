# 轻醒 · 自用 Wi-Fi 打卡提醒

[当前正式安装包与验证记录](release/INSTALL.md) · [正式交付记录](release/latest.json)

本仓库 `qingxing_android` 保存安卓源码和已有 APK。`qingxing_ios` 仅预留仓库，暂不开发 iOS 版本。

源码中的应用功能对应 1.1.1；公开源码前仅调整构建凭据读取与仓库文档，没有重新打包或修改历史 APK。百度 AK、签名密钥及签名密码不在源码仓库中，构建前请按 [构建说明](docs/BUILD.md) 配置自己的本地文件。已有正式版本的覆盖升级必须沿用原签名。

Android 9 及以上；不依赖 Google Play 服务。打卡提醒只根据绑定的公司 Wi-Fi 名称判断。独立“定位”页提供按需百度定位、小地图，以及安卓官方模拟位置测试功能。

- 工作日、有效上下班时段、未确认时，每 10 秒读取一次当前 Wi-Fi。
- 每轮监控开始满一分钟后，在固定的一分钟节点检查：上班连接公司 Wi-Fi 时提醒，下班未连接时提醒。
- 监控固定保持安静；打卡提醒每次响铃和振动 5 秒，短铃声循环补足，到时自动停止，不提供稍后按钮。名称相同的接入点视为同一网络；关闭 Wi-Fi 或读取失败按未连接处理。
- 确认、时段结束、非工作日或关闭总开关，停止当前监控和提醒；Wi-Fi 条件反转取消当前提醒。
- 取消勾选清除旧状态，重新开始一分钟计时。上班确认不会关闭下班计划。
- 首页“去企微打上班卡”“去企微打下班卡”打开企微后直接确认对应打卡、停止提醒，不再询问；打开失败不确认。请在企微完成实际打卡，误操作可双击已确认按钮取消。
- “最近动态”用日常用语展示，滚动区域高度为原来的 3 倍，最多保留 100 条，错误标红。保留通知确认同步、法定调休日历及本地备份。

公司设置只保留 Wi-Fi 名称、上下班时段和总开关。系统可能要求位置相关权限才能读取 Wi-Fi 名称；打卡监控不会请求经纬度；独立定位工具仅在主动使用并同意百度服务后获取位置。后台需允许通知、闹钟和后台运行；手机系统限制可能影响实际轮询时机。读取失败按未连接处理是本版明确的业务规则。

覆盖升级保留 Wi-Fi、时间、日历、打卡确认和历史；清理旧位置/半径/接入点/阈值、旧五分钟提醒与循环响铃状态。新版备份 schema=4，兼容旧版备份，只导入仍有效的设置。

构建和发布通过 [构建说明](docs/BUILD.md) 的统一入口。源代码、旧 APK 和私人密钥不随安装包发布。

定位工具：底部“定位”页可获取一次当前位置，或拖动地图后点击“开始模拟”。系统开发者选项需选择轻醒为模拟位置应用；模拟时保留可停止的常驻通知，切换应用后继续，重启后不自动启动。点击“当前位置”会先停止模拟。其他应用可能拒绝模拟位置，需以目标测试应用实测为准。百度 SDK 在同意服务前不初始化；权限、网络或鉴权失败会显示原因。

定位入口默认隐藏：在“设置”底部版本号文字与右侧说明图标之间的空白处连续点击 10 次（相邻间隔不超过 2 秒）后显示“定位”。切到后台保留本次解锁，关闭重开或进程重新启动后恢复隐藏；旧页面状态和通知入口不能绕过解锁。模拟通知的停止按钮保持可用。
